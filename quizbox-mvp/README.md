# QuizLAN (QuizBox) — Локальная платформа для проведения викторин

Веб-приложение «сервер + клиент», запускаемое на устройстве организатора и доступное участникам через браузер во внутренней (локальной) сети Wi-Fi/LAN без доступа к интернету. Все данные хранятся локально в базе данных SQLite.

##  Стек технологий и запуск проекта
* **Backend:** Python (FastAPI) / Node.js (Express)
* **База данных:** SQLite
* **Frontend:** HTML5, CSS3, JavaScript

###  Инструкция по запуску:
1. Клонировать репозиторий: `git clone https://github.com`
2. Установить зависимости: `pip install -r requirements.txt` *(или `npm install`)*
3. Запустить локальный сервер: `uvicorn backend.main:app --host 0.0.0.0 --port 8000` *(или `npm start`)*

##  Правила работы с Git (Git Flow)
* **`main`** — стабильная ветка, прямые коммиты запрещены.
* **Рабочие ветки** создаются от `main` под каждую задачу: `feature/FR-01-описание`, `fix/RISK-04-описание`, `docs/DOC-01-описание`.
* **Сообщения коммитов** начинаются с кода задачи из Yougile: `FR-01: добавлена схема БД SQLite`.
* Слияние в `main` выполняется исключительно через **Pull Request** после проверки (Code Review) другим участником команды.
